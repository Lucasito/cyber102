# Афиша культуры Башкортостана

Хакатон «Кибер102», задача №1 (Министерство культуры РБ). Единая достоверная афиша культурных событий
республики: сайт с поиском и фильтрами, умный помощник (ИИ-агент), боты в MAX и Telegram, открытый REST API
и виджет для сторонних сайтов.

**Сайт:** https://afish.193-47-33-213.sslip.io

> Полная документация задачи ещё не вышла. Реальные источники событий не подключены — в базе тестовые
> события (помечены источником `demo`, на сайте видна плашка «Тестовые данные»).

## Что умеет

| | |
|---|---|
| **Сайт** | Поиск и фильтры: дата (сегодня / завтра / выходные / период), город, жанр, цена, «бесплатно», возраст, Пушкинская карта, доступная среда, «рядом со мной». Сортировка (дата, цена, новые, расстояние). Вид «Списком / На карте». Статусы событий. Страница события: карта и маршрут, «В календарь» (.ics), «Поделиться», ссылка на источник. Русский и башкирский. Мобильная вёрстка. SEO: sitemap, schema.org Event, картинки-превью ссылок. |
| **Умный помощник** | Свободный запрос («куда пойти в субботу с ребёнком до 1000 ₽») → уточняющий вопрос, если запрос размытый → подборка **только из базы** с объяснением. Помнит контекст диалога. Работает и без ИИ (правила + шаблон). |
| **Боты MAX и Telegram** | Тот же помощник в мессенджерах. Меню команд, кнопки-подсказки, ссылки на события, «печатает…», напоминания о событиях («🔔»). |
| **REST API и виджет** | Открытый API без ключа (OpenAPI 3.1), виджет одной строкой — во фрейме, не затрагивает сайт, на котором стоит. |
| **Админка** | Невидимая, вход по секретной ссылке. Тексты сайта, ИИ (провайдер, модель, ключи, лимиты GigaChat, нагрузка), боты, аналитика запросов («чего не хватает в афише»), тестовые данные. |
| **Защита** | Лимит запросов к помощнику (настраивается: по умолчанию 600/мин и 10 000/сутки с адреса, 150/мин и 2000/сутки на пользователя бота), очередь к ИИ, работа без ИИ, автостатус «прошло». |
| **Настройки** | Все рабочие параметры (таймауты, повторы, кэш, размеры выдачи, радиус, сроки напоминаний, тексты помощника) и выбор карты (OpenStreetMap / Яндекс) — в админке, без правки кода. |

## Быстрый старт (локально)

Нужны Node.js 22 и Docker.

```bash
cp .env.example .env          # DATABASE_URL уже указывает на локальную БД; задайте ADMIN_KEY (≥16 символов)
npm install
npm run db:up                 # PostgreSQL 16 в Docker на 127.0.0.1:5435
npm run db:migrate
npm run seed:demo             # 38 тестовых событий (только локальная БД)
npm run dev                   # http://localhost:3000
```

Ключи ИИ и токены ботов задаются в админке: `http://localhost:3000/admin/enter/<ADMIN_KEY>`.
Проверка ИИ из консоли: `npm run ai:check`.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Сервер разработки |
| `npm run typecheck` / `npm run lint` | Проверка типов и линтер (перед коммитом) |
| `npm run db:up` / `db:migrate` / `db:deploy` | Локальная БД, миграции |
| `npm run seed:demo` (`-- --clear`) | Загрузить (удалить) тестовые события |
| `npm run ai:check [-- "вопрос"]` | Проверить подключение ИИ |
| `npm run logo:export` | PNG логотипа из `public/brand/logo.svg` |
| `bash scripts/deploy.sh` | Деплой на сервер (Git Bash) |
