Для следующего адаптера особенно удобны «Родина», два Ultra Cinema, «Мир кино» и «Синема 5»:
в страницах уже видны сеансы с ценами и возрастом. Это техническая оценка по проверке страниц, а не
подтверждённый доступ к API. JSON-LD может описывать организацию, а не сеансы; наличие блока не считается
готовым Event-источником. Локальный результат проверки загрузки — `test-results/cinema-source-probe.json`.

Приоритет для первого адаптера — «Мираж»: HTML расписания уже доступен. Затем «Кинопорт» и остальные
сети/муниципальные кинозалы. Согласовать регулярную выгрузку с владельцами; хранить локальный кэш,
обновлять по расписанию, ссылаться на официальный сеанс. Избегать платного ИИ для структурированного
списка киносеансов. Проверять актуальную дату в ответе — индексированная поиском страница бывает устаревшей.

Поиск источников не подключает их автоматически: адаптеры кинотеатров и активные источники для них
в этом изменении не добавлялись. Автодополнение существующих культурных событий — отдельный механизм,
описанный в [DATA_QUALITY.md](DATA_QUALITY.md).
