## Подключение

Подключены 12 кинотеатров — индивидуальные парсеры без ИИ (`lib/server/collect/cinemas.ts`), источники
добавляет `npm run sources:seed` **выключенными**: модератор включает каждый в админке («Источники»).
Один сеанс — одно событие категории «Кино» с постоянным `externalId`; собираются 5 ближайших дней,
прошедшие сеансы пропускаются, ночной сеанс (до 05:00) относится к следующему календарному дню.
Ссылка на источник — страница расписания или фильма на официальном сайте.

| Парсер | Кинотеатры | Откуда данные |
|---|---|---|
| `cinema-premierzal` | «Кинопорт», «Фонтан», «Металлург» | `/schedule?date=ДД.ММ.ГГГГ`; сайт ставит cookie города и перенаправляет — загрузка с cookie (`fetchText({ cookies: true })`) |
| `cinema-rodina` | «Родина» | Главная: 4 дня сеансов Kinoplan в HTML |
| `cinema-ultra` | Ultra Cinema ×2 | `/?date=ГГГГ-ММ-ДД`, залы и длительность |
| `cinema-cinemapark` | «Синема Парк» ×2 | Страница кинотеатра `?date=ГГГГ-ММ-ДД` |
| `cinema-mirage` | «Мираж» «Арбат» | `/str/schedule/ДД.ММ.ГГГГ/`, минимальная из цен (обычная/льготная) |
| `cinema-p24` | «Мир кино» | JSON расписания в данных страницы Next.js; точное время сеанса |
| `cinema-cinemabox` | «Синема 5» | Ссылки на фильмы с главной, на странице фильма — 5 дней (данные Nuxt) |
| `cinema-arsenal` | «Арсенал» | Главная, вкладки дней «14 ноября» |

Проверка: `npm run test:cinemas` (правила дат и строк), `npm run test:cinemas -- --live` — загрузить все сайты и
посчитать сеансы (0 или ошибка — структура сайта изменилась). robots.txt соблюдается, как у всех источников.

Сеансов много (у «Синема Парка» — 200+ на 5 дней): без «автопубликации» они идут в модерацию. Данные
структурированы и берутся с официального сайта, поэтому после проверки источника разумно включить автопубликацию.

**Не подключены:** Киномакс «Планета» (CAPTCHA), «Горняк» в Кумертау (нет расписания на сайте),
«Супер 8» в Туймазах и КРК «Аврора» в Бирске (сеансы загружаются только скриптом в браузере).

Автодополнение существующих культурных событий — отдельный механизм, описанный в [DATA_QUALITY.md](DATA_QUALITY.md).
