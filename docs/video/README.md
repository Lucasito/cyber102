# Резервная демонстрация

[Открыть видео — afisha-demo-5min.mp4](afisha-demo-5min.mp4)

Пять минут, 1920 × 1080, MP4, русская озвучка голосом Microsoft Svetlana Neural, без ускорения речи. [Короткий пример голоса](voice-preview.mp3). Для воспроизведения интернет не нужен. Скопируйте файл на компьютер выступающего и проверьте звук в его проигрывателе.

В видео видна крупная стрелка мыши с оранжевым ободком. В момент нажатия появляется расширяющийся оранжевый круг. Переходы между страницами, заполнение полей и выбор параметров показаны действиями указателя. Эта подсветка добавляется только во время записи и не меняет сам сайт.

Это запись настоящего сайта, с настоящими ответами помощника и событиями на дату записи. Ответы и карточки не подменяются. В записи показаны публичные страницы; заявки не отправляются. Защита вживую: [сценарий и реплики](../DEMO.md).

## Повторная запись

Нужны Google Chrome, Python и библиотеки Python `playwright`, `imageio-ffmpeg`, `edge-tts`. Для создания новой озвучки нужен интернет: текст сценария отправляется в службу синтеза речи Microsoft. Их установка не меняет зависимости самого сайта:

```powershell
python -m pip install playwright imageio-ffmpeg edge-tts
python -m playwright install ffmpeg
python -X utf8 scripts/record-demo.py --rehearse
python -X utf8 scripts/record-demo.py
```

Команды запускаются из корня проекта. Первый запуск проверяет все действия без записи и длительных пауз. Второй длится около шести минут, включая сохранение файла. Браузер работает в отдельном временном сеансе, не затрагивая вкладки и учётные записи пользователя.

Текст и отметки разделов: [scenes.json](scenes.json). Исходная запись, звук, снимки экранов и сведения о кликах сохраняются в `test-results/demo-recording/`, который исключён из Git. Готовый файл заменяется после успешного сохранения и проверки. Чтобы повторить запись с уже подготовленным голосом, используйте `python -X utf8 scripts/record-demo.py --reuse-voice`.

Перед новым выступлением проверьте, что найденные события ещё актуальны. Запись сохраняет дату и ответы прежнего показа; её содержимое само не обновляется.
