# Избранное и план дня

## Избранное без регистрации

Сердце на карточке или странице события сохраняет конкретный сеанс. `/favorites` показывает актуальные
сведения, позволяет сравнить даты, места, цены и возрастные ограничения. Удалённые или снятые с публикации
события отображаются как недоступные, их можно убрать из списка.

В браузере хранится только JSON-массив ID: `localStorage["afisha-rb:favorites:v1"]`, максимум 100 событий.
Аккаунт и запись пользователя в базе не создаются, cookie для избранного не устанавливаются. Карточки
загружаются публичным запросом `/api/v1/events/batch?ids=…`; сервер не сохраняет список избранного.
Изменения видны в других вкладках того же сайта и браузера. Между устройствами синхронизации нет.

Очистка данных сайта удаляет список. В приватном режиме срок зависит от браузера. Если хранилище запрещено
или переполнено, список работает в памяти открытой страницы, а интерфейс предупреждает, что сохранение
между посещениями недоступно. Повреждённые данные и неверные ID отбрасываются.

ТЗ §6.3 требует работу **виджета без сторонних cookies**, а не общий запрет cookie. В `/widget` избранное
отключено; виджет не зависит ни от `localStorage`, ни от cookie. Существующие настройки языка и вход
в админку имеют отдельную механику и не участвуют в избранном.

## Уведомления об изменениях

Сохранение в избранное само по себе не включает рассылку. Кнопка на сайте открывает бота MAX или Telegram,
где человек подтверждает подписку. При обращении к боту используется существующая запись `BotUser`:
платформа и идентификатор в мессенджере, без имени. Подтверждение создаёт `EventWatch` — связь с событием,
снимок публичных полей и даты создания/проверки. Браузерное избранное с ботом не связывается и не переносится.

Отслеживаются дата, статус, название, площадка, город, адрес и цена. Полные описания и персональные данные
в снимке не хранятся. Подписка удаляется через `/watches` или `/unwatch ID`, все подписки — `/unsubscribe`.
Автоочистка — через 30 дней после окончания события; задача запускается раз в час. Удаление события или
пользователя бота также удаляет подписки. Повторное подтверждение не создаёт дубль.

Проверка идёт по 50 подписок за минутный тик. При ошибке отправки снимок не обновляется, следующая проверка
повторяет попытку. Это не мгновенные push-уведомления браузера. Автоматический статус «прошло» отдельно
не сообщается. Снятое с публикации событие вызывает общее сообщение без содержимого черновика.

## План дня

`/plan` доступен без регистрации. Дата, город, возраст младшего участника, число людей, бюджет на всех,
временное окно, число событий, способ передвижения и типы мероприятий (флажки категорий; по умолчанию
отмечены все, ничего не отмечено — тоже все) задаются формой. Типы передаются параметром `types`. Результат — 2–4 события с временем
посещения, суммой известных цен, переездами, картой и ссылкой на маршрут.

«Заменить событие» сохраняет остальные остановки и исключает заменённое из следующих вариантов.
Общая ссылка содержит условия и ID выбранных событий; при открытии доступность и цены проверяются заново.
Если событие отменено или больше не подходит, показывается объяснение. План на сервере не сохраняется.
Кнопка календаря экспортирует посещения одним `.ics`; даты и длительность соответствуют построенному плану.

Переезды приблизительны: расстояние по прямой, условные скорости для транспорта/автомобиля/пешего пути,
без пробок и расписаний. Между залами одного здания переезд равен нулю. Нет точных координат — принимается
20 минут с предупреждением. Без времени окончания используется длительность события либо 120 минут;
гибкое посещение выставки — указанная длительность либо 90 минут, окно по умолчанию 10:00–18:00.
Предположения о длительности обозначены. Неизвестная цена предупреждает о неполной сумме; транспорт в бюджет
не входит. Точные часы работы, цену и проезд нужно проверять у организатора.

## Проверка и выпуск

`npm run test:visitor:browser` создаёт отдельную временную PostgreSQL-базу, применяет миграции, запускает
собранное приложение и проверяет API, согласие/отписку, уведомления с подставным отправителем, избранное
в двух вкладках, запрет хранилища, отсутствие cookie и мобильный маршрут. Реальным пользователям сообщения
не отправляются. Скриншоты — `test-results/favorites-mobile.png` и `test-results/plan-mobile.png`.

Перед запуском теста нужны локальная БД, Edge или Chrome и `npm run build`. Для выпуска применяются все
миграции через `npm run db:deploy`, включая `20261114150000_event_watches`, затем сборка и перезапуск приложения.
