# Защита: 3 минуты показа + 4 минуты вопросов

Формат организаторов: онлайн, 7 минут на команду. **Постановку проблемы не делаем** — сразу показ работающего
решения. Время по расписанию — как в объявлении (не пересчитывать в ЕКБ/МСК/UTC). Резервное видео — обязательно.

Сайт: https://afisha.193-47-33-213.sslip.io · Админка: `/admin` · Бот: Telegram и MAX

## Накануне

1. **Данные.** Админка → «Источники»: последние сборы без ошибок и без красной отметки «⚠». «Модерация» —
   очередь разобрана. На главной есть события на день защиты, включая кино.
2. **Прогнать сценарий целиком 2 раза с секундомером** — уложиться в 2:50.
3. **Записать резервное видео** (ниже) и проверить, что оно открывается с того компьютера, с которого идёт показ.
4. Админка → «Качество» → «Проверить точность сейчас» — чтобы на вопрос о качестве данных показать свежий отчёт.

## За 10 минут

1. Админка → «ИИ-помощник» → «Проверить ИИ» — отвечает GigaChat. Если нет — показ идёт в резервном режиме, это
   тоже часть решения (см. вопросы).
2. Один любой запрос в чате — прогреть модель (первый ответ после простоя дольше).
3. Вкладки браузера по порядку: **главная** · **/plan** · **админка → Трассы** · **админка → Источники** ·
   **eval/report.md**. В Telegram — чат с ботом, `/new`.
4. Закрыть лишние окна и уведомления, масштаб браузера 110–125 % (видно в трансляции), демонстрировать окно браузера.

## Резервное видео

- Записать **ровно этот сценарий**, 3 минуты, с голосом, 1080p. Windows: Xbox Game Bar (`Win + Alt + R`) или OBS.
- Сохранить локально **и** загрузить (Яндекс Диск / Google Drive) со ссылкой «доступ по ссылке» — ссылку держать
  открытой во вкладке.
- В видео не должно быть паролей, токенов, писем: перед записью выйти из лишних вкладок, в админке не открывать
  разделы с ключами («ИИ-помощник», «Боты», «Почта»).

## Если что-то пошло не так

| Ситуация | Что делать |
|---|---|
| ИИ не отвечает или долго думает | Админка → «ИИ-помощник» → снять «Умный поиск включён» и повторить запрос: подборка по тем же условиям обычным поиском. «Именно для этого и сделан резервный режим» |
| Нет сети / сайт не открывается | Сразу включить резервное видео, не чинить в эфире |
| Бот не отвечает | Пропустить шаг, сказать «бот — тот же помощник» и перейти к админке |
| В подборке ничего нет | Это честный ответ «ничего не нашлось» — сказать об этом и задать запрос шире («на выходных») |

## Вопросы — 4:00: короткие ответы

Отвечать 1–2 предложениями и, если можно, **показать** (в скобках — куда переключиться).

- **Откуда события, не выдуманы ли?** Только из источников: ленты и страницы учреждений, 12 кинотеатров (свои
  парсеры, без ИИ), импорт файлов и кабинет организаторов. У каждого события — ссылка на источник; разобранное ИИ
  и присланное организаторами — только через модерацию. (Карточка → «Источник»; админка → «Источники».)
- **Как модель не выдумывает?** Модель выбирает инструмент и пишет 1–2 фразы; список событий формирует код из
  результатов поиска по базе. Фактическая точность 100 %, выдуманных событий 0 на 96 кейсах. (Трассы; eval/report.md.)
- **Насколько точна сама афиша?** Отдельная метрика: 50 карточек автоматически сверяются со страницей источника —
  название, дата, время, цена; плюс доля дублей и ошибки импорта по категориям. (Админка → «Качество» →
  «Точность афиши».)
- **Что если модель недоступна?** Резервный режим: условия разбирают правила, текст — шаблон; так же при
  превышении лимита стоимости. (Снять «Умный поиск включён» и показать.)
- **Сколько стоит?** GigaChat, около 0,87 ₽ за диалог; лимиты по стоимости и запросам — в админке.
- **Отмены и переносы?** Источники перепроверяются; перенос сохраняет прежнюю дату, отменённые не показываются
  как актуальные, подписчикам — уведомление. На прямой вопрос «отменили ли…» — ответ по базе со ссылкой.
- **Не нагружаете ли чужие сайты?** Сбор раз в сутки, к одному сайту — не чаще запроса в 3 секунды, при ответе
  «слишком часто» сайт не трогаем 30 минут; соблюдение robots.txt — переключатель в «Источниках».
- **Источник сломался — как узнаете?** Число записей сравнивается с обычным; ноль, резкое падение или ошибки
  подряд — письмо администратору и отметка в админке.
- **Как встроить?** REST API `/api/v1` с OpenAPI (`/docs`) и виджет одной строкой (`/docs/widget`), в том числе
  на башкирском.
- **Учреждение хочет добавить события?** Кабинет организатора (через модерацию) или лента в универсальном
  формате (`/docs/format`) — тогда ИИ не нужен.
- **Почему не свободный tool-calling?** Дороже, медленнее и не гарантирует отсутствие выдумок
  ([DECISION.md](DECISION.md)); взяли из него выбор инструмента моделью и лимит вызовов.
- **Чего не умеет?** Время суток («после 19:00») и длительность как фильтр; поджанры — кроме балета, оперы,
  оперетты, мюзикла; «рядом» — только с разрешения на геопозицию. Подробно — «Границы применимости» в
  [DECISION.md](DECISION.md).
- **Персональные данные?** Регистрация не нужна; избранное хранится в браузере, геопозиция не сохраняется,
  диалоги удаляются через 30 дней.
