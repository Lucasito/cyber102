# Боты MAX и Telegram

> **Общий выключатель ботов** — `BOTS_PAUSED` в `lib/server/settings.ts` (сейчас `false`, боты работают). При `true`
> боты не работают при любых настройках админки: опроса нет, webhook отвечает 404, ссылок на сайте нет, напоминания и
> рассылки копятся и уйдут после включения.

Два способа искать (ТЗ 6.2):

- **кнопками, без ИИ** — меню, дата, город, категория, цена, «Показать ещё», карточка события, подписки; работает
  всегда, даже когда ИИ недоступен (`lib/server/bot-browse.ts`, поиск — тот же `searchEvents`);
- **свободным текстом** — тот же умный помощник, что на сайте: уточнения, подборка из базы с объяснением, память
  диалога (последние 10 реплик). Без ИИ отвечает обычным поиском по правилам и пишет об этом.

| «печатает…» | ✅ | ✅ |
| Напоминания («🔔» под событием) | ✅ | ✅ |

## Команды и меню

`/start` — приветствие и **главное меню на кнопках**: Сегодня, Завтра, Выходные, Неделя, Город, Категория, Выбрать
дату, Цена, Бесплатно, С ребёнком, Подписки, Помощь.

| Команда | Действие |
|---|---|
| `/start` | Приветствие с меню; диалог и фильтры сбрасываются |
| `/menu` | Меню поиска |
| `/today`, `/weekend` | Сегодня / ближайшие выходные (поиск кнопками, без ИИ) |
| `/free`, `/kids`, `/pushkin` | Бесплатные / с ребёнком 6+ / по Пушкинской карте |
| `/plan` | План на выходной день через помощника: 2–4 события без накладок, переезды, общая сумма (кнопка «🗓 План на выходной» в меню) |
| `/subs` | Мои подписки (кнопка ✕ — отписаться от одной) |
| `/unsubscribe` | Отписаться от всех подписок одной командой |
| `/reminders` | Мои напоминания |
| `/cancel` | Сбросить поиск (фильтры и диалог) |
| `/help` | Как пользоваться |
| свободный текст | Запрос к умному помощнику: «концерт в Стерлитамаке в субботу до 1000 ₽» |

**Поиск кнопками.** Фильтры складываются и запоминаются (`BotUser.browse`): «Выходные» → «Город: Уфа» →
«Категория: Театр». Список — по 5 событий (настройка «Событий в ответе бота»): когда, где, цена, возраст;
многодневные — «идёт до …». «Показать ещё (5 из 12)» листает дальше; под списком — смена города, категории, даты,
цены, «Подписаться», «Сбросить» — к меню возвращаться не нужно. Пусто — бот пишет, какое условие ослабить, и даёт
кнопку: «Без даты (4)».

**Карточка события** (кнопка с названием): категория, название, статус (отменено / перенесено с прежней датой),
дата и время, город, площадка и адрес, цена или «бесплатно», Пушкинская карта, возраст, язык, описание, ссылка на
источник; кнопки «Источник», «Билеты», «На сайте», «🔔 Напомнить», «← К списку».

## Подписки

«🔔 Подписаться» под списком — подписка на **текущие город и категорию** (пусто — «все»). Подписка оформляется
только после кнопки подтверждения (изменение данных — с подтверждением, ТЗ 6.5). До 10 подписок на пользователя.

Рассылка (`sendSubscriptionDigests` в `lib/server/jobs.ts`): с 10:00 до 21:00 по местному времени, проверка раз в
час, каждому — **не чаще раза в 20 часов**, одно сообщение со всеми новыми событиями его подписок (до 8), только
если появилось новое. В подписке хранятся только идентификатор пользователя и фильтр; `/unsubscribe` или ✕
удаляют запись.

## «Рядом со мной»

На «рядом», «около меня», «поблизости» бот просит геопозицию кнопкой: в Telegram — кнопка обычной клавиатуры
с `request_location` (инлайн-кнопки так не умеют), в MAX — `request_geo_location`. Пришла геопозиция — бот повторяет
последний запрос вокруг неё (радиус «Рядом со мной» из тонкой настройки) и пишет расстояние у событий; «Искать без
местоположения» — тот же запрос по всей афише. Координаты используются только в этом поиске: в диалог, трассу и
логи не пишутся.

Команды регистрируются автоматически при запуске бота (`PATCH /me/commands` в MAX, `setMyCommands` в Telegram).

## MAX

1. business.max.ru → Чат-боты → создать бота типа «Добавление в чаты» → скопировать токен.
2. Админка → «Бот MAX» → токен, включить, «Проверить бота».

Работает через long polling (`GET /updates`), HTTPS-домен не нужен. Режим webhook (`MAX_MODE=webhook` в
`.env`, `MAX_WEBHOOK_SECRET`, подписка на `/api/max/webhook`) поддержан, но не используется.

API MAX и GigaChat подписаны сертификатом Минцифры — он в `certs/russian_trusted_root_ca.pem`.
Документация API: https://dev.max.ru/docs-api (хост — `platform-api2.max.ru`).

## Telegram

### Почему через посредника

С сервера в РФ Telegram заблокирован **в обе стороны**: сервер не может обратиться к
`api.telegram.org`, а Telegram доставляет webhook с таймаутами — сообщения приходили с задержкой в минуты.
Поэтому сервер ходит в Telegram через **Cloudflare Worker** — зеркало API (Cloudflare с сервера доступен).

### Настройка

1. @BotFather → `/newbot` → токен.
2. Cloudflare Worker (бесплатный тариф):
   dash.cloudflare.com → Workers & Pages → Create → «Start with Hello World!» → имя → Deploy →
   Edit code → вставить [docs/telegram-proxy-worker.js](telegram-proxy-worker.js) → Deploy.
   Воркер пропускает только запросы нашего бота (по id из токена, список `ALLOWED_BOT_IDS` в коде) —
   открытым прокси он не станет. Для другого бота добавьте его id.
3. Админка → «Бот Telegram»: токен, «Адрес API Telegram» = адрес воркера
   (сейчас `https://afisha-tg.alcomsoft-str.workers.dev`), режим «Опрос», включить, «Проверить бота».

Если раньше был включён webhook, бот снимет его сам при первом опросе.

### Режим webhook (запасной)

Telegram сам присылает сообщения на `/api/telegram/webhook`, ответ возвращается прямо в теле HTTP-ответа —
исходящий доступ к Telegram не нужен. Регистрация — ссылкой «Подключить webhook» в админке, открытой в
браузере, где Telegram доступен. Секрет webhook вычисляется из токена. Из-за блокировки входящих сообщения
доходят с задержкой — использовать, только если воркер недоступен.

## Напоминания

Под каждым событием в подборке — кнопка «🔔». Бот напомнит:

- обычное событие — за сутки до начала, а если до начала меньше суток — за 2 часа (меньше чем за 2 часа —
  «напоминать поздно»);
- выставку и другое многодневное событие — за 2 дня до закрытия («успейте посетить»);
- если событие отменили или перенесли — напоминание об этом скажет.

Напоминания хранятся в таблице `Reminder`, отправляет их фоновая задача раз в минуту (`lib/server/jobs.ts`).
`/reminders` — список с кнопками «✕» для отмены. В Telegram напоминания уходят через Cloudflare Worker (в режиме
webhook исходящих запросов нет — напоминания не отправятся).

## Лимиты

По умолчанию не больше 150 запросов к помощнику в минуту и 2000 в сутки на пользователя — защита токенов ИИ
от спама. Меняется в админке (ИИ → Нагрузка → Лимиты).
Команды меню, напоминания и сброс диалога в лимит не входят.

## Как устроено

- `lib/server/bot-core.ts` — общая логика: команды, сброс, вызов агента, хранение диалога, `BotReply`.
- `lib/server/max.ts`, `lib/server/telegram.ts` — API мессенджеров, кнопки, циклы опроса.
- Циклы запускаются в `instrumentation.ts` и проверяют настройки каждые несколько секунд: включение,
  выключение и смена токена применяются без перезапуска.
- Одного бота нельзя одновременно опрашивать с двух серверов: при локальной разработке заведите отдельного
  тестового бота.
- Если MAX не примет сообщение с кнопками, бот отправит ответ текстом со ссылками.
