# Боты MAX и Telegram

> **Сейчас боты выключены:** `BOTS_PAUSED = true` в `lib/server/settings.ts`. Пока флаг стоит, боты не
> работают при любых настройках админки: опроса нет, webhook отвечает 404, ссылок на сайте нет,
> напоминания копятся и уйдут после включения. Чтобы включить ботов, поставьте `false` и задеплойте.

Оба бота — тот же умный помощник, что на сайте: свободный запрос, уточнения, подборка из базы с объяснением,
память диалога (последние 10 реплик на пользователя).

## Команды и меню

| Команда / кнопка | Действие |
|---|---|
| `/start` | Приветствие с меню, диалог сбрасывается |
| `/today` · «Сегодня» | Что идёт сегодня |
| `/weekend` · «На выходных» | Ближайшие выходные |
| `/free` · «Бесплатно» | Бесплатные события |
| `/kids` · «С ребёнком» | Для детей (6+) |
| `/pushkin` | По Пушкинской карте |
| `/reminders` | Мои напоминания (с кнопками отмены) |
| `/new` · «Новый поиск» | Сбросить диалог |

Команда превращается в обычный запрос к помощнику, поэтому условия складываются: «На выходных» →
«Бесплатно» = бесплатные события на выходных. Команды регистрируются автоматически при запуске бота
(`PATCH /me/commands` в MAX, `setMyCommands` в Telegram).

## MAX

1. business.max.ru → Чат-боты → создать бота типа «Добавление в чаты» → скопировать токен.
2. Админка → «Бот MAX» → токен, включить, «Проверить бота».

Работает через long polling (`GET /updates`), HTTPS-домен не нужен. Режим webhook (`MAX_MODE=webhook` в
`.env`, `MAX_WEBHOOK_SECRET`, подписка на `/api/max/webhook`) поддержан, но не используется.

API MAX и GigaChat подписаны сертификатом Минцифры — он в `certs/russian_trusted_root_ca.pem`.
Документация API: https://dev.max.ru/docs-api (хост — `platform-api2.max.ru`).

## Telegram

### Почему через посредника

С сервера в РФ Telegram заблокирован **в обе стороны**: сервер не может обратиться к
`api.telegram.org`, а Telegram доставляет webhook с таймаутами — сообщения приходили с задержкой в минуты.
Поэтому сервер ходит в Telegram через **Cloudflare Worker** — зеркало API (Cloudflare с сервера доступен).

### Настройка

1. @BotFather → `/newbot` → токен.
2. Cloudflare Worker (бесплатный тариф):
   dash.cloudflare.com → Workers & Pages → Create → «Start with Hello World!» → имя → Deploy →
   Edit code → вставить [docs/telegram-proxy-worker.js](telegram-proxy-worker.js) → Deploy.
   Воркер пропускает только запросы нашего бота (по id из токена, список `ALLOWED_BOT_IDS` в коде) —
   открытым прокси он не станет. Для другого бота добавьте его id.
3. Админка → «Бот Telegram»: токен, «Адрес API Telegram» = адрес воркера
   (сейчас `https://afisha-tg.alcomsoft-str.workers.dev`), режим «Опрос», включить, «Проверить бота».

Если раньше был включён webhook, бот снимет его сам при первом опросе.

### Режим webhook (запасной)

Telegram сам присылает сообщения на `/api/telegram/webhook`, ответ возвращается прямо в теле HTTP-ответа —
исходящий доступ к Telegram не нужен. Регистрация — ссылкой «Подключить webhook» в админке, открытой в
браузере, где Telegram доступен. Секрет webhook вычисляется из токена. Из-за блокировки входящих сообщения
доходят с задержкой — использовать, только если воркер недоступен.

## Напоминания

Под каждым событием в подборке — кнопка «🔔». Бот напомнит:

- обычное событие — за сутки до начала, а если до начала меньше суток — за 2 часа (меньше чем за 2 часа —
  «напоминать поздно»);
- выставку и другое многодневное событие — за 2 дня до закрытия («успейте посетить»);
- если событие отменили или перенесли — напоминание об этом скажет.

Напоминания хранятся в таблице `Reminder`, отправляет их фоновая задача раз в минуту (`lib/server/jobs.ts`).
`/reminders` — список с кнопками «✕» для отмены. В Telegram напоминания уходят через Cloudflare Worker (в режиме
webhook исходящих запросов нет — напоминания не отправятся).

## Лимиты

По умолчанию не больше 150 запросов к помощнику в минуту и 2000 в сутки на пользователя — защита токенов ИИ
от спама. Меняется в админке (ИИ → Нагрузка → Лимиты).
Команды меню, напоминания и сброс диалога в лимит не входят.

## Как устроено

- `lib/server/bot-core.ts` — общая логика: команды, сброс, вызов агента, хранение диалога, `BotReply`.
- `lib/server/max.ts`, `lib/server/telegram.ts` — API мессенджеров, кнопки, циклы опроса.
- Циклы запускаются в `instrumentation.ts` и проверяют настройки каждые несколько секунд: включение,
  выключение и смена токена применяются без перезапуска.
- Одного бота нельзя одновременно опрашивать с двух серверов: при локальной разработке заведите отдельного
  тестового бота.
- Если MAX не примет сообщение с кнопками, бот отправит ответ текстом со ссылками.
