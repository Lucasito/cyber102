## Порядок работ

1. **Этап 0** — пункты 0.1–0.6 (меньше дня, снимает «красные линии»).
2. **Данные** — схема 8.1, публикация / черновик, `RawRecord`, `AuditLog`, импорт CSV/JSON с отчётом, дедупликация,
   ручное редактирование и модерация в админке.
3. **Бот уровня 1** — инлайн-меню, кнопочный поиск без ИИ, полная карточка, «показать ещё», подписки.
4. **API и сайт уровня 2** — справочники, подписки, обратная связь, формат ошибок, кеширование, метрики, request id,
   `docker compose up` целиком.
5. **Агент уровня 3** — инструменты, трассировка, уточнения, резервный режим с плашкой, лимиты стоимости, 20+
   запросов и первые метрики.
6. **Сдача** — README (уровень, модель, стоимость), DEMO.md, DECISION.md, запись экрана.
7. **Уровень 4** — сбор из 2 источников, нормализация, проверка, планировщик, 60 запросов и отчёт с baseline
   (пороги: точность ≥ 98 %, ограничения ≥ 90 %, уточнения ≥ 90 %, задержка p95 ≤ 6 с, диалог ≤ 3 ₽).
