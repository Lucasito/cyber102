# Задание: иллюстрации-заглушки категорий событий

## Контекст

Сайт афиши культуры Башкортостана (Next.js + Tailwind). У многих событий из источников не будет фото.
Сейчас без фото карточка показывает пастельную подложку категории и одну иконку lucide в углу —
на странице события (`app/(site)/events/[id]/page.tsx`) это большой пустой прямоугольник.
Нужны простые векторные иллюстрации по категориям, чтобы заглушка выглядела как задуманная картинка.

Перед началом посмотри:
- `components/event-card.tsx` — карточка (плитка 16:9 на десктопе, миниатюра 96 px шириной на телефоне);
- `lib/format.ts` — `CATEGORY_STYLE`: цвет подложки и акцента для каждой категории;
- `public/brand/logo.svg` — стиль логотипа (плоский, белые фигуры, без теней) как ориентир по характеру линий.

Запусти локально (`npm run db:up`, `npm run seed:real`, `npm run dev`) — снимок реальной афиши.

## Что нарисовать

По одному SVG на категорию, `public/illustrations/<slug>.svg`:

| slug | Категория | Мотив (предложение, можно лучше) |
|---|---|---|
| `theatre` | Театр | занавес, сцена, маски |
| `concert` | Концерты | ноты, микрофон или скрипка |
| `exhibition` | Выставки | рамы картин на стене |
| `museum` | Музеи | колонны, витрина с предметом |
| `kids` | Детям | кукла-перчатка, шарики |
| `cinema` | Кино | кинолента, хлопушка |
| `festival` | Фестивали | флажки-гирлянда, сцена под открытым небом |
| `lecture` | Лекции | кафедра, раскрытая книга |
| `excursion` | Экскурсии | дорожка, указатель, холмы Урала |
| `default` | Без категории | цветок курая (как в логотипе) |

Требования:
- `viewBox="0 0 640 360"` (16:9). Композиция с запасом: ключевой объект в центральной трети,
  чтобы при обрезке до квадрата-миниатюры на телефоне (`object-cover`, центр) он оставался виден.
- Плоский стиль, 2–3 цвета на иллюстрацию: фон — светлый оттенок категории (как `bg-*-100` в `CATEGORY_STYLE`),
  фигуры — более насыщенные оттенки того же цвета (`*-300`…`*-500`) и белый. Все иллюстрации — одна серия:
  одинаковая толщина линий, скругления, плотность деталей.
- Без текста, букв, логотипов, узнаваемых зданий и людей с лицами. Символику министерства и герб не использовать.
- Ручной читаемый SVG, без растровых вставок и внешних ссылок, до 6 КБ на файл.

## Подключение

1. В `lib/format.ts` добавь функцию `illustrationFor(slug?: string | null): string` → путь
   `/illustrations/<slug>.svg` или `/illustrations/default.svg`.
2. В `components/event-card.tsx` и на странице события: если `imageUrl` нет — показывать иллюстрацию
   (`<img>` с `object-cover`, `alt=""`) вместо подложки с иконкой. Иконку `CategoryIcon` убрать из заглушки.
   Подложку `CATEGORY_STYLE` оставь как фон под картинкой (на время загрузки).
3. Остальной дизайн и логику не меняй.

## Проверка

- `npm run typecheck` и `npm run lint` без ошибок.
- Скриншоты главной (1280 px и 390 px) и страницы события без фото — приложи в ответе или опиши, что проверил.
- На телефонной ширине в миниатюре 96 px виден главный объект каждой иллюстрации.
