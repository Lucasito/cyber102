# REST API и виджет

Афиша открыта для сайтов и приложений: API без ключа, CORS разрешён для всех источников.
Базовый адрес: `https://afish.193-47-33-213.sslip.io`. Машиночитаемая спецификация — `GET /api/v1/openapi`
(OpenAPI 3.1). Страница для людей — `/docs`.

## Поиск событий

`GET /api/v1/events`

| Параметр | Тип | Описание |
|---|---|---|
| `q` | string | Поиск по названию, описанию и площадке |
| `city` | string | Город: `Уфа`, `Стерлитамак`… |
| `category` | string | Жанр: `theatre`, `concert`, `exhibition`, `museum`, `kids`, `cinema`, `festival`, `lecture`, `excursion` |
| `dateFrom`, `dateTo` | date | `YYYY-MM-DD` (местное время UTC+5) или полная дата ISO. Без `dateFrom` — с текущего момента |
| `priceMax` | int | Минимальная цена билета не выше, ₽ |
| `free` | bool | Только бесплатные (`true`/`1`) |
| `age` | int | Возраст зрителя: события с ограничением не выше |
| `status` | enum | `SCHEDULED`, `RESCHEDULED`, `CANCELLED`, `SOLD_OUT`, `PAST`. По умолчанию — все, кроме прошедших |
| `pushkin` | bool | Только события, которые можно оплатить Пушкинской картой |
| `access` | enum | Доступная среда: `wheelchair` — на коляске, `hearing` — для слабослышащих, `vision` — для слабовидящих |
| `near` | string | Рядом с точкой: `широта,долгота` (например `54.7348,55.9579`). В ответе у событий — `distanceKm` |
| `radius` | number | Радиус для `near`, км: 1–300, по умолчанию 15 |
| `sort` | enum | `date` — по дате (по умолчанию), `price_asc` — сначала бесплатные и дешёвые, `price_desc` — сначала дорогие, `new` — недавно добавленные, `distance` — ближе к точке `near`. Без цены — в конце |
| `limit` | int | 1–100, по умолчанию 20 |
| `offset` | int | Смещение для постраничной выдачи |

Период ищется по пересечению: выставка, идущая месяц, попадает в выдачу на любой день внутри срока.

```bash
curl "https://afish.193-47-33-213.sslip.io/api/v1/events?city=Уфа&dateFrom=2026-11-14&dateTo=2026-11-15&age=6&priceMax=1000"
```

Ответ:

```json
{
  "items": [
    {
      "id": "cm…",
      "title": "Сказка о царе Салтане",
      "startsAt": "2026-11-14T06:00:00.000Z",
      "endsAt": "2026-11-14T08:30:00.000Z",
      "status": "SCHEDULED",
      "priceMin": 400, "priceMax": 600,
      "ageLimit": 0,
      "imageUrl": null, "ticketUrl": "…",
      "venue": { "name": "Театр кукол «Сказка»", "city": "Уфа", "address": "…" },
      "category": { "slug": "kids", "name": "Детям" },
      "sources": [{ "source": "…", "url": "…" }]
    }
  ],
  "total": 7, "limit": 20, "offset": 0
}
```

Цены — в рублях; `priceMin: 0` — бесплатно, `null` — цена неизвестна. Даты — UTC (ISO 8601).
Неверные параметры — `400` с описанием (`issues`).

## Событие

`GET /api/v1/events/{id}` — событие с площадкой, категорией и источниками; `404`, если нет.

## Умный поиск (ИИ-агент)

`POST /api/ai/chat`

```json
{ "messages": [
  { "role": "user", "content": "куда пойти в субботу с ребёнком до 1000 рублей" }
] }
```

Для продолжения диалога передайте всю историю (до 20 реплик, роли `user` / `assistant`) — агент учтёт
прежние условия («а в воскресенье?»).

Ответ:

| Поле | Описание |
|---|---|
| `text` | Объяснение подборки или уточняющий вопрос |
| `events` | Найденные события (как в `/api/v1/events`) — только из базы |
| `suggestions` | Подсказки для кнопок («Бесплатно», «С ребёнком»…) |
| `clarify` | `true`, если это уточняющий вопрос |
| `filter` | Применённый фильтр |

Ошибки: `503 ai_disabled` — умный поиск выключен в админке; `400` — неверное тело; `429 rate_limited` — превышен
лимит (по умолчанию 600 запросов в минуту и 10 000 в сутки с одного адреса, настраивается в админке; заголовок `Retry-After` — через сколько секунд можно
повторить). При перегрузке ИИ ответ всё равно приходит (подборка по правилам, объяснение по шаблону), но может
задержаться до минуты — запросы стоят в очереди.

Необязательное поле `lang`: `"ba"` — помощник отвечает по-башкирски (`"ru"` — по умолчанию).

## Виджет

Вставьте в любое место страницы:

```html
<div data-afisha-widget data-city="Уфа" data-limit="6"></div>
<script src="https://afish.193-47-33-213.sslip.io/widget.js" async></script>
```

| Атрибут | Описание |
|---|---|
| `data-city`, `data-category`, `data-age`, `data-price-max`, `data-free` | Фильтры, как в API |
| `data-limit` | Сколько событий показать (по умолчанию 6) |
| `data-height` | Высота фрейма, px (по умолчанию 480) |

Виджет работает во фрейме (`/widget?…`): стили и скрипты сайта не затрагиваются, сайт министерства менять
не нужно. Карточки открывают событие на сайте афиши в новой вкладке. Встраивание во фрейм разрешено только для
`/widget`, остальные страницы афиши во фрейм не встраиваются.
